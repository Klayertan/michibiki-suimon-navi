## 2. ケーブルは支柱ではない / The tether is not a pole

**これが設計上いちばん重要な制約です。**

係留ケーブルの役割は3つだけです。

1. 流されないようにする
2. 電源を供給する
3. （任意）シリアル/データを通す

ケーブルは **浮体の高さを決めてはいけません**。

* 剛性のある棒のように振る舞ってはいけない
* 特定の高さに浮体を保持する意図で張ってはいけない
* 想定水位範囲**全域**で、浮力が鉛直位置を決めるだけの柔らかさと弛みが必要

**張ったケーブルは鉛直力を生み、測定を汚染します。** ケーブルが張った瞬間、
浮体は水面ではなくケーブル長を測り始めますが、その切り替わりはログ上では
ただの「水位が変わらなくなった」ようにしか見えません。**弛みは安全余裕ではなく
測定条件です。**

弛み量の目安: 想定水位範囲の全高（例 150 mm）に対し、アンカーから浮体までの
直線距離の**2倍以上**のケーブル長。余ったケーブルは浮体側でまとめず、
水底付近でゆるく蛇行させます（浮体側に重さを足すと喫水が変わります）。

弾性センシング素子として**モデル化しません**。ケーブルの伸びから水位を推定する
設計ではありません。

## 4. アンテナ配置 / GNSS antenna placement

アンテナは:

* 浮体の**最上部**に
* **上向き**に
* 水面からできるだけ**高く**（実用的な範囲で）
* 不要な導体から離す
* 可能なら大容量バッテリーや電子回路から離す

筐体はアンテナを金属で不必要に覆わないこと。

**この配置自体が実験対象です。** 水面はGNSSにとって良好な反射面であり、アンテナが
水面に近いほどマルチパスが増えます。「水面と水田環境が許容できないマルチパス／
ノイズを持ち込むかどうか」を確かめることも、この実験の目的の一つです。
アンテナ高を変えて2回走らせる価値があります。

浮体は波と風で傾きます。傾きはアンテナのパターンを動かし、見かけの標高を
変えます。第1段階（固定治具）と第2段階（浮体）を比べる意味はここにあります。

## 5. 防水 / Waterproofing

**3Dプリントしたから防水、ということはありません。** プリント造形物は層間に
微小な通路が残ります。次の2つは、他が完璧でも漏れる経路です。

1. **筐体の合わせ目 / seam** — 溝＋Oリングを基本にし、シールに接着を兼ねさせない
2. **ケーブル貫通部 / cable penetration** — グランドはケーブル外径に適合したものを選ぶ。
   適合しないグランドを増し締めしてもシリコン被覆が潰れるだけです

シール材は**中性硬化型**シリコーンを使ってください。一般的な酢酸系（硬化時に
酢酸臭がするもの）は硬化中に酢酸を出し、内部の銅・はんだ・端子を腐食させます。
密閉した筐体の中でこれをやると、防水した箱の中で腐食を育てることになります。

### ひずみ緩和 / Strain relief

グランドは防水部品であって、機械的な固定具ではありません。ケーブルに掛かる張力が
グランドのシールに直接伝わる構造にしないこと。浮体内側でケーブルに結び目または
ケーブルタイによるストッパを設け、**引っ張り荷重はグランドではなく筐体で受ける**
ようにします。

繰り返し曲げは被覆を切ります。グランド直近が曲げの支点にならないよう、外側に
ゆるい曲率を持たせてください。

### 結露 / Condensation

昼夜の温度差で、密閉筐体の内部は結露します。水は一滴も入っていなくても、
組み立て時に閉じ込めた空気の湿分だけで基板に水滴が付きます。

* 乾燥した室内で、できれば乾燥剤（シリカゲル小袋）を入れて組む
* 湿度の高い日に屋外で開閉しない
* 内部にインジケータ付き乾燥剤を入れると、点検時に状態が読めます

「浸水していないのに動かない」の相当部分は結露です。

### 腐食 / Corrosion

水田の水は中性とは限らず、施肥直後は特にそうです。

* 露出する金属はステンレス（バラストのワッシャ、アンカー、アイボルト）
* 異種金属の接触を避ける（ステンレスと亜鉛メッキの併用など）
* コネクタは筐体の**内側**に。外部コネクタは、それ自体が防水対象になります

### 泥 / Paddy mud

浮体は必ず泥をかぶります。

* 表面は滑らかに（プリント積層痕は泥を抱きます）
* 泥の付着は質量を増やし、喫水を変えます。**測定中に少しずつ沈みます**
* 実験の前後で浮体を秤に載せ、質量変化を記録してください。これはノイズではなく
  系統誤差であり、標高のドリフトと区別がつきません

### 清掃 / Cleaning

* 真水で洗う。高圧洗浄はグランドとOリングに向けない
* アンテナ上面は柔らかい布で。研磨材は使わない
* 洗浄後は完全に乾かしてから保管。濡れたまま密閉すると内部で結露します

### 保守性 / Serviceability

* **開けられること。** 恒久接着で密閉した筐体はデバッグできません
* Oリング溝は再組立てできる設計に。毎回シールし直す構造は、毎回失敗し得ます
* 開けた回数を記録する。シールは開閉ごとに劣化します
* 浮体内部に、受信機のシリアル/USBに手が届く構造を残す

## 6. 安全 / Safety

* 水と泥の中の機器です。**プロトタイプの電圧は低く保つこと**
* 圃場側のセンサに**商用電源電圧を持ち込まない**
* 必要に応じて電流制限・ヒューズを入れる（ケーブルは踏まれ、切られ、短絡します）
* **リチウム電池を水に直接晒さない**
* 第1実験では外部低電圧給電を優先。電池の防水はGNSS検証とは別の課題です
